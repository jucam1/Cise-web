La HP 15 cw100 es una laptop de gama media con procesador AMD que llegó al taller con dos particularidades: la batería no funciona (el equipo solo opera conectado a la corriente) y el sistema operativo requería una instalación limpia. El cliente necesitaba el equipo listo para trabajo de oficina, por lo que se realizó la instalación de Windows 11 y Microsoft Office.

¿Qué se hizo? Se realizó instalación limpia de Windows 11 en la HP 15 cw100. Se instaló y configuró Microsoft Office para uso inmediato. El equipo opera correctamente conectado a corriente. La batería no fue parte de este servicio: el equipo ingresó al taller sin batería funcional.

Estado del equipo al ingreso

  • Sistema operativo con problemas — requería instalación limpia
  • Batería sin funcionar — equipo solo opera con cargador conectado
  • Sin Office instalado — necesario para trabajo de oficina

Proceso de instalación

1. Preparación del disco y arranque

Se preparó el medio de instalación de Windows 11 y se configuró el equipo para arrancar desde él. Antes de formatear se verificó que el hardware fuera compatible con Windows 11 (procesador AMD Ryzen compatible, TPM 2.0 activo).

2. Instalación limpia de Windows 11

Se realizó una instalación limpia de Windows 11, formateando la partición del sistema para eliminar cualquier software previo, archivos temporales acumulados y configuraciones incorrectas. Una instalación limpia parte de cero y garantiza el mejor rendimiento desde el inicio.

3. Instalación de controladores

Se instalaron los controladores oficiales de HP para la plataforma cw100: chipset, gráficos AMD, red inalámbrica, audio y dispositivos de entrada. Los controladores correctos son esenciales para el rendimiento óptimo y la estabilidad del sistema.

4. Instalación de Microsoft Office

Se instaló Microsoft Office y se configuró para uso inmediato. El equipo quedó listo con Word, Excel, PowerPoint y los demás componentes necesarios para trabajo de oficina.

5. Verificación final

Se verificó el correcto funcionamiento del sistema operativo, la conectividad WiFi, el audio y los periféricos. El equipo fue entregado listo para usar, operando con cargador conectado dado que la batería no es funcional.

Preguntas frecuentes

¿Puedo usar la laptop HP 15 cw100 sin batería?

Sí. La laptop funciona normalmente conectada al cargador. La batería es independiente del funcionamiento del sistema: su ausencia o falla no afecta el rendimiento mientras haya corriente. Para uso en escritorio o puesto fijo esto es perfectamente viable. Si necesitas movilidad, el reemplazo de batería es una reparación sencilla.

¿Qué diferencia hay entre una instalación limpia y una restauración?

Una restauración regresa el sistema al estado de fábrica pero puede conservar algunos problemas de software acumulados. Una instalación limpia formatea completamente el disco del sistema y parte de cero, eliminando cualquier software no deseado, virus, configuraciones incorrectas o fragmentación del sistema. Es la opción más recomendable cuando el equipo presentaba fallas de software.

¿Cuánto tiempo tarda un formateo con instalación de Windows y Office?

En la mayoría de los casos el servicio se entrega el mismo día. La instalación de Windows 11 con controladores y Office toma entre 2 y 4 horas dependiendo de las actualizaciones pendientes y la velocidad del disco del equipo.
